# EGG HATCH — フロントエンド + バックエンド 接続版

漫画・物語制作のための共同制作コミュニティ「EGG HATCH」。
これまで別々に作っていたフロントエンド(HTML/CSS/JS)とバックエンド(Flask)を、
1つのアプリとして接続しました。**これ以降、`preview/` フォルダは不要です。**
`backend/app.py` を起動するだけで、実際のデータベースにつながった状態で
画面を確認できます。

## フォルダ構成

```
egg-hatch/
├── backend/            ← Flaskアプリ本体。ここを起動する
│   ├── app.py            起動ファイル
│   ├── models.py         データベースのテーブル定義
│   ├── auth.py           ログイン・会員登録
│   ├── works.py          作品・応募・選考・チームのAPIと権限チェック
│   ├── files.py          ファイルアップロード
│   ├── profiles.py       クリエイタープロフィール
│   ├── pages.py          画面(HTML)を配信するルート
│   ├── init_db.py        データベースの初期化・サンプルデータ投入
│   └── README.md         バックエンドの詳しい説明
│
├── templates/          ← 画面のHTML(Flaskが配信する)
├── static/
│   ├── css/               各画面のスタイル
│   ├── js/                各画面の動作(バックエンドAPIを呼び出す)
│   └── images/            背景画像・ロゴ
│
└── docs/
    └── egg-hatch-db-design.md   データベース設計ドキュメント
```

## 動かし方

```bash
cd backend
pip install -r requirements.txt
python3 init_db.py     # データベースを作成し、サンプルデータを入れる
python3 app.py          # サーバー起動
```

ブラウザで `http://127.0.0.1:5000/` を開くと、トップページが表示されます。

**お試し用アカウント**(すべてパスワード `password123`):
- `tachibana@example.com`(発案者。「境界線のアリス」などの作品を持っています)
- `kamiya@example.com` / `kitano@example.com` / `yonaga@example.com` / `fukami@example.com`(応募者側)

新規登録もログイン画面からできます。

## ひととおり試せる操作

1. トップページで作品カードやクリエイターカードを見る(実データ)
2. 作品詳細ページで、募集中の役割を確認する
3. ログインして、役割に応募する(ファイル添付も本物のアップロード)
4. 発案者としてログインし直し、選考画面で応募を確認・採用する
5. 採用されると、その場で「制作スペースへ進む」リンクが出る
6. 採用されたメンバーとしてログインし、制作スペース(メンバー一覧は実データ)に入る
7. クリエイタープロフィールを見る・編集する(本人のみ編集可)
8. 新しい作品/アイデアを投稿する

## 番外編について

本編とは別に「番外編 -リレー漫画-」を追加しました。誰かが描いた続きを別の人がつなぐ、
プロ・アマ問わず参加できる仕組みです。トップページ下部、または `egg-hatch-relay.html`
から入れます。詳しくは `backend/README.md` の「番外編」の項目を参照してください。

## まだ接続・実装できていない部分(正直な現状)

- **キャラクター設定**：保存する仕組み(テーブル)がまだ無く、作品詳細ページには表示されません
- **制作進捗(%)**：正確な値を管理する仕組みが無いため、「募集役割のうち埋まった割合」で代用しています
- **プロフィールの参加作品・過去の提出作品・完成作品**：まとめて取得するAPIがまだ無く、準備中の表示です
- **制作スペースのチャット・ラフ提出・ファイル共有一覧**：専用のテーブルがまだ無く、
  画面を開いている間だけの一時的な機能のままです(ファイルの実アップロードだけは本物です)
- **ジャンル・応募用課題・募集期限**：作品投稿フォームには入力欄がありますが、まだ保存されません
